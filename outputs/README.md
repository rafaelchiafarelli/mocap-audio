# Outputs

Store generated prototype clips, render exports, and evaluation notes here.

Keep naming consistent:

- `YYYYMMDD_01_prompt-name.wav`
- `YYYYMMDD_02_prompt-name.mp3`
- `YYYYMMDD_notes.md`

Every generated sample should be tied to:

- the prompt,
- the model used,
- the seed or generation settings,
- the reason it was created,
- whether it is approved or just a prototype.
